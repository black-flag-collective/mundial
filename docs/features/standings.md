# 📊 Standings — computed group tables

Live tables for all **12 groups**, derived directly from the match results —
not hand-entered.

## What you see

- A table per group with the standard columns, marking the teams currently
  **advancing to the Round of 32** (top two per group).
- A **timestamp** showing when the underlying data was last updated.

## What you can do

- **Hover a team** to trace it on the globe below.

## How it stays accurate

The tables are computed from the same match data that powers
[Matchday](matchday.md). When a result lands, the standings recompute — there's
no separate, hand-maintained table to drift out of sync.
